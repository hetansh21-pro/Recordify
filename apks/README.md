# Recordify Official Releases

This directory contains the public build APKs for **Recordify**:

| APK File | Target Platform | Architecture | Min Android Version | Description |
|---|---|---|---|---|
| **[`Recordify.apk`](./Recordify.apk)** | Android Mobile & Tablet | ARM64 / x86_64 | Android 10+ (API 29+) | High-fidelity music streaming, smart audio capture, YouTube ad-cutter, offline downloader, and Spotify taste importer. |
| **[`Recordify TV.apk`](./Recordify%20TV.apk)** | Android TV & Google TV | ARM64 / x86_64 | Android 10+ (API 29+) | 10-foot TV experience with full TV remote control navigation, fixed bottom mini-player, rotating vinyl full-screen player, 1-click remote discovery, and intelligent era-matching queue engine. |

### Installation Instructions
1. Download the respective APK file for your device.
2. Enable **Install from Unknown Sources** in your device Settings.
3. Open the file on your device to install.
